This repository contains components developed as part of **Work Package 2 (WP2)** of the SustainML project.

WP2 focuses on **selecting suitable machine learning models and execution hardware** based on the problem requirements and constraints provided by earlier stages of the framework.

## Scope

The components in this repository are designed to:

- Evaluate constraints related to performance, memory, and resources
- Identify candidate hardware platforms for model execution
- Support informed trade-offs between model capabilities and system limitations

## Usage

WP2 module is not intended to operate independently and are integrated into the broader SustainML pipeline.

For installation, configuration, and execution instructions, refer to the main framework repository:

https://github.com/eProsima/SustainML-Framework
